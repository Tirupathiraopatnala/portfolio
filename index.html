B2B Lead Generation and Enrichment Platform

Data Pipeline + LLM

A multi-source pipeline that pulls company and contact records from LinkedIn, Apollo, Hunter.io and Google Maps and turns them into one qualified list. Two-stage LLM screening: intent classification over post comments, then a deeper qualification pass that scores each lead. Built the data quality layer that post-filters vendor results against their real industry classification, after keyword-tag matching started returning wildly irrelevant companies. Also removed the LLM from the company discovery flow entirely once it began inventing selection criteria, because deterministic filters turned out cheaper and more reliable. Every run is cancellable, so external API spend stops the moment you hit stop. Built on my own initiative and presented to the sales team and CEO.

n8n Knowledge Assistant

RAG + Multi-Agent

Enterprise chatbot that routes queries across internal and external knowledge sources using a classifier-based dispatcher. Internal path uses vector and semantic retrieval over indexed docs; external path runs a multi-stage pipeline with intent resolution, document discovery and schema enrichment across a GitHub repo via MCP. Both paths run in parallel and get merged, which keeps latency down. Conversation traces and user feedback are captured and fed into a DeepEval loop to reduce hallucination over time.
